1 · Users
Visitor
public pages · inquiry form
Client
own matters · messages · documents
Lawyer
assigned matters · internal notes
Admin
intake · users · content · audit
2 · Presentation & delivery
React 19 single-page app — Vite 8 · TypeScript 5.7 · Tailwind 4
role-aware dashboards for client, lawyer and admin · supabase-js client · realtime subscriptions · xlsx report exports · nothing sensitive in the browser but the anon key
Vercel — hosting & delivery
static build from the repo · global CDN · HTTPS · SPA routing — serves the app, never the data
3 · Platform services
Supabase — the entire backend, no custom server
auth · api · realtime · storage · functions
Auth
email + password · confirmed signup · JWT session carried on every request
PostgREST API
table reads & writes under RLS · RPCs: submit_inquiry · convert_inquiry_to_matter · break_glass_open_document
Realtime
live notifications and matter updates pushed while signed in
Storage
documents bucket (private) · lawyer-photos (public read) · path-scoped policies
Edge Functions
admin-create-user · admin-delete-user — service role stays server-side
4 · Data at rest — PostgreSQL · RLS on every table
Identity & roles
profiles · profile_practice_areas · public_lawyers view
Intake
inquiries — status workflow · reference numbers · audit trail
Matters
matters · matter_members · matter_notes · matter_events · appointments
Documents
documents · confidential_access_grants (break-glass)
Notifications & audit
notifications · audit_logs — trigger / client stamped
Public content
practice_areas · articles · specialists · corporate_clients · faqs · seminar_events · retainer_packages
5 · Cross-cutting security
RLS ON EVERY TABLE
policies are the only gate — client · lawyer · admin roles
SERVER-SIDE FUNCTIONS
SECURITY DEFINER with pinned search_path — no privilege leaks
AUDIT TRAIL
every sensitive action stamped trigger vs client · append-only
BREAK-GLASS
admin-only · reason ≥ 15 chars · 15-minute expiry · audited
HTTPS
supabase-js · JWT session
SQL under row-level security
Legend The browser talks only to Supabase — every request carries the user's JWT and is filtered by RLS No custom server · no service-role key in the client · one source of truth: PostgreSQL
